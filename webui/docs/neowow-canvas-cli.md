# NeoWoW 画布连接

Agent 已内置官方 `neowow-canvas` Skill 和 `neowow` 命令。CLI 包来自：
https://wlpaas.oss-cn-shanghai.aliyuncs.com/agent/neowow-canvas/neowow-canvas-skill.zip

当前内置版本为 `v0.5.0+cef7cd13.20261003T040441Z`。随应用发布更新，首次
启动无需联网下载安装；已有 CLI 文件保留，Studio 的创作和凭据指引会同步更新。Docker 镜像已有
Node.js，桌面端需要 Node.js 18 或更新版本，以及支持 HOME 会话上下文的
新版 Hermes Agent。旧版 Agent 暂停 Key 绑定并提示更新。

## 用户操作

1. 打开「设置 → Neowow Studio → NeoWoW 画布」。
2. 点击「生成 API Key」打开 `neowow.cn`，在官网登录并进入「用户中心 → CLI」。
3. 生成 Key，粘贴到设置页的隐藏输入框，点击「保存并连接」。
4. 连接成功后直接告诉 Agent 要完成的画布任务。

## 接入画布、创作和交付

1. 连接成功后，在「创作工作区」点击「载入我的画布」。支持文件夹与分页，
   选择已有画布，也可以输入名称新建一张。
2. 创作前关闭目标画布网页；协作画布需要确认房间无人。勾选确认项后，填写
   要求并选择分镜、图片、视频、音频或文本。视频／分镜默认先写剧本，其他类型
   点击「交给 Agent 创作」。
3. 请求进入当前聊天，Agent 先给出文字或方案；媒体生成先展示模型和 CLI 积分
   预估，确认后才提交付费生成。进度与结果使用现有聊天流。当前聊天忙碌、只读、属于
   其他 Profile 或输入框已有草稿／附件时，不覆盖内容，也不发送任务。
4. 完成后回到「最终结果」，点击「提取／刷新结果」。可预览图片、播放视频
   和音频、阅读及下载文本，也可以打开媒体原文件保存，或导出 JSON 结果清单。

### 先剧本、后片段

1. 选择「视频」或「分镜画布」，填写故事主题、人物、观众和风格，设置目标总
   时长（10–600 秒）与画幅，点击「生成剧本逐字稿」。使用当前聊天选择的大模型
   写故事、分场动作、完整对白与旁白、说话人、情绪和时间段。这一步不调用画布的
   `gen text/image/video/audio`；聊天模型仍按当前 Coding Plan／模型计费方式运行。
2. Agent 展示全文并用官方 CLI 将文字保存为「剧本逐字稿 · 初稿／修订稿」文本
   节点。回到工作区点击「提取剧本」，在文本结果卡片点击「载入逐字稿」。也可
   填写已有剧本。直接编辑文字，或填写修改意见后点击「请 Agent 修改剧本」；
   修订稿保留旧版本，再次提取并选择要采用的版本。
3. 勾选逐字稿审阅确认，点击「准备分镜与视频方案」（分镜类型准备图片方案）。
   修改文字、创作要求、时长、画幅或类型后，旧确认失效。用户编辑暂存在当前
   页面，刷新前应通过 Agent 保存到画布；已保存节点可以重新提取。切换画布、
   Profile、断开或更换凭据会清空编辑与确认，迟到的旧结果不会恢复剧本。
4. Agent 保存确切的确认版，逐句对应编号镜头，安排动作、景别、机位、转场、
   声音与人物连续性，并依据模型支持的单片时长拆分节点。剧本确认不代表消费
   确认：先展示每镜、参考素材及配音的 CLI 积分预估与总计，用户再次确认后才
   生成媒体。每个视频片段交付对应台词、节点标识、实际状态、预览与原文件链接。

写作与媒体阶段通过同一原生聊天 Agent 执行，不另外建立文本模型接口，也不
自动选择其他账号。CLI 目前没有文档化的多片段合成命令，这里交付有序片段，
没有自动拼接成一条成片。后台检查逐字稿非空与 literal `scriptConfirmed: true`，
工作区检查确认生命周期；付费工具调用的审批仍依赖 Agent 遵守 Skill 与聊天
确认指引，不是工具层面的强制消费沙箱。

画布读取、新建和任务状态查询都通过官方 CLI。结果提取是只读操作，会检查
生成任务是否完成，不触发新的生成，也不修改画布。结果来自当前节点的输出，
排除上传参考素材、正在生成节点的旧结果和失败结果；历史版本暂不合并到结果区。
图片／视频／音频保留原始 HTTPS 结果链接，服务端不代下载或代理任意媒体 URL。
媒体预览使用浏览器的 HTTPS 图片／音视频权限，不扩大脚本来源；无法加载预览
时仍保留原文件链接。导出清单通过带附件标记、禁止缓存的接口交付。

所选画布按当前 Profile 与画布凭据隔离；更换 Key 后需要重新选择，防止复用
旧账号的画布。创作流程使用显式 sessionId，不会修改工作目录的项目绑定。
断开或更换凭据会清除浏览器里的旧画布及结果状态。

连接区会分别展示画布工具和运行环境的就绪状态。连接成功后收起密钥表单，
显示创作示例；需要更换凭据时点击「更换 Key」，取消时清空输入。验证期间
按钮与输入暂时禁用，防止重复提交；更换失败会保留旧连接并允许重试。

全程不需要执行命令，也不需要把密码或 Key 发给 Agent。密码仅由官网处理。
Key 验证后保存在当前 Profile 的私有配置中；输入框在提交时立即清空。
「断开连接」只清除本地凭据，不撤销官网 Key；重新生成 Key 会立即使旧 Key
失效，也会影响其他正在使用旧 Key 的客户端。状态页显示的是本地是否已保存，
实际访问是否有效由 CLI 判断。

画布 Key 与 Studio 部署 Token、Coding Plan Key 不同，不能互换。公共共享
实例不提供个人 Key 绑定；专属 Agent 实例或桌面端可以绑定。每个 Profile
分别连接账号。聊天使用官方 HOME／session ContextVars，并在终端读取共享
快照后重新绑定本轮 HOME，防止并发 Profile 误用另一个账号；已有网页在 Profile
切换时清除结果并丢弃迟到响应。CLI 运行在同一个操作系统用户下，文件权限与 Skill 指引防止
误泄漏；这不是对 Agent 文件访问的强制密钥隔离。

## 一键生成并绑定的下一步

当前官方发布包只说明「官网生成后复制」流程；尚未确认受支持的 Key 创建／
授权接口，因此本次没有自动调用未知的创建接口。实现完全免复制流程需要
NeoWoW 服务端提供浏览器授权：

- 用户点击「连接画布」，跳转到官方登录与授权页面，密码由官网处理。
- 服务端签发短时、一次性的授权码，绑定当前账号、Agent 实例、回调与 state；
  回调传授权码，不传 Key。桌面仅允许当前 localhost 回调，云端使用已登记回调。
- Agent 服务端验证 state 并通过后端交换取得 CLI 可接受的凭据，写入当前
  Profile。浏览器与聊天仅获得连接结果，不获得 Key。
- 已有 Key 的复用或换发须有明确的用户提示；不要因重复连接而静默使旧 Key
  失效。需要撤销连接、授权码过期和账号／实例不匹配的失败行为。

需确认服务端接口、鉴权机制、账号归属与返回格式后才能接入；不能直接把
Studio JWT 当成 CLI API Key。
